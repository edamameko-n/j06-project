# 寝坊抑止アラームアプリ（j06-project）

## 1. 企画概要
本アプリは、設定した起床時刻にアラームを鳴らし、猶予時間内に起床確認ができなかった場合に、事前設定した内容を Discord / Googleフォーム へ自動送信することで、寝坊への心理的抑止を活用し、規則正しい起床習慣の形成を支援します。

## 2. 目的
- 二度寝・寝坊を防ぐきっかけを作る
- 自動投稿による心理的抑止効果で起床習慣を改善する
- 起床履歴の可視化で生活習慣の振り返りを可能にする
- 欠席・遅刻連絡の送信漏れを減らす

## 3. 想定ユーザー
- 朝起きるのが苦手な学生
- 朝の授業・アルバイトに遅刻しがちな人
- 二度寝を防ぎたい人

## 4. 基本フロー
1. 起床時刻・曜日・アラーム音を設定
2. 寝坊時の投稿先（Discord / Googleフォーム）と送信文面を設定
3. 設定時刻にアラームを鳴動
4. ユーザーが起床確認操作を実施
5. 猶予時間内なら「起床成功」として記録
6. 猶予時間超過なら「寝坊」と判定
7. 条件に応じて自動送信を実行（Discord投稿 / Googleフォーム送信）
8. 実行結果を履歴へ保存（成功/失敗を含む）

## 5. MVP要件
- アラーム設定（起床時刻・曜日・音）
- 起床確認（ボタン操作）
- 寝坊判定（時刻 + 猶予時間）
- 自白メッセージ設定
- 投稿処理（優先: Discord Webhook、Googleフォーム）
- 起床履歴（起床時刻、寝坊回数、成功率）
- 投稿先・投稿内容・自動送信の有効/無効設定
- 初回設定時の自動投稿同意確認
- 送信失敗時の結果記録と通知

## 6. 投稿先優先度
- **高（MVP）**: Discord Webhook
- **高（MVP）**: Googleフォーム（GAS連携）
- **低（要検討）**: X API v2

## 7. 技術構成
- フレームワーク: Flutter
- 言語: Dart
- 対応OS: まず Android、将来的に iOS
- DB: SQLite（端末内）
- 秘密情報保存: OS安全領域（例: flutter_secure_storage）
- サーバー: 初期は非採用（将来導入検討）

## 8. 連携仕様
### Discord
- Webhook URLへ HTTP POST で送信
- Webhook URLは機密情報として扱う

### Googleフォーム
- Google Apps Script（Forms Service）で `FormResponse.submit()` を利用
- Flutter から GAS Webアプリへ HTTP リクエスト
- 実運用フォームは権限要件（編集権限）を事前確認

## 9. セキュリティ・運用要件
- Webhook URL等の秘密情報をソースコードやDBに平文保存しない
- 送信結果（成功/失敗）を必ず記録
- 誤送信・二重送信防止を考慮
- 通信失敗時は未送信キューを保持し、通信回復後に再送

## 10. Android実装上の注意
- 画面オフ/未起動時の判定・送信を想定
- Doze制約を考慮し、正確なアラームと通知を組み合わせる
- Android 12+ の正確なアラーム権限要件を満たす
